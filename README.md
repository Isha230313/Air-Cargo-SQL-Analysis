# ✈️ Air Cargo Analysis --- SQL Project

A SQL data analysis project focused on exploring airline customer,
passenger, route, and ticket data to identify travel trends, route
activity, revenue patterns, and customer behaviour.

## Project Overview

The project uses MySQL queries to analyze air cargo and airline-related
datasets. It demonstrates SQL techniques for retrieving, combining,
aggregating, and transforming structured data to answer
business-oriented questions.

## Key Analysis

-   Identified passengers travelling across selected routes.
-   Calculated Business class passenger count and total revenue.
-   Analyzed customers with ticket bookings and airline brand
    preferences.
-   Explored Economy Plus travel activity.
-   Checked whether overall ticket revenue crossed a defined threshold.
-   Calculated maximum ticket prices by travel class.
-   Used indexing and execution plans for route-based queries.
-   Calculated ticket booking totals across customers and aircraft.
-   Classified routes into short, intermediate, and long-distance
    categories.
-   Evaluated complimentary service eligibility by travel class.
